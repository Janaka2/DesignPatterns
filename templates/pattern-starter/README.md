# Pattern Starter Template

Use this folder as the base for adding a new pattern to the repository.

## What to include

1. **Intent**: one sentence on the design problem solved.
2. **When to use**: concrete triggering conditions.
3. **Trade-offs**: at least two downside risks.
4. **Real-world mapping**: one enterprise scenario.
5. **How to run tests**: exact Maven command.

- Pattern name:

- Target package:
- Key dependencies (if any):
- Related test class:

## Required files

- `src/main/java/.../PatternTemplate.java`
- `src/test/java/.../PatternTemplateTest.java`
- `EXTENSION_POINTS.md`

## Definition of done

- Example compiles.
- Test verifies positive and negative/edge behavior.
- Extension points documented for workplace customization.
